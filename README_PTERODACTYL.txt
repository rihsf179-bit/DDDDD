Pterodactyl / AA Panel
======================

1. อัปโหลดและแตก ZIP ลงโฟลเดอร์โปรเจกต์
2. เลือก Python 3.11 หรือใหม่กว่า
3. สร้าง .env จาก .env.example แล้วใส่ค่าทั้งหมด
4. Startup command: python -u bot.py
5. Install dependencies: python -m pip install -r requirements.txt
6. เปิดเซิร์ฟเวอร์
7. ตั้ง volume/storage ให้โฟลเดอร์ data อยู่ถาวร

ถ้าจะตั้งใน aaPanel ให้รันจากโฟลเดอร์โปรเจกต์ด้วย virtualenv และตั้ง systemd/process manager ให้ restart อัตโนมัติ
